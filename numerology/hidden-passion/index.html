How it is calculated

  1. Convert all letters in the full birth name to values 1–9.
  2. Count every occurrence of each value.
  3. Find the highest count. If values tie for the highest count, keep all of them; do not add them together.
Conventions worth knowing

This explains the existing calculator’s frequency rule. A set of tied values is not a new combined number. Detailed researched profiles have not been published.
